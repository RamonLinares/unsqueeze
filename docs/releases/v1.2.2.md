# Unsqueeze 1.2.2

## Changes in 1.2.2

- Runs only on `meet.google.com`. The legacy `hangouts.google.com` hostname, which Google has retired, is no longer included.
- Prepares Unsqueeze for the Chrome Web Store: the build adds a store package, and the repository includes the listing text, privacy answers, and store images.

Video processing and settings are unchanged from 1.2.1, and existing preferences are kept.

Correct anamorphic webcam proportions in Google Meet. Camera- and lens-brand independent, with local video processing.

## Download and install

Download **Unsqueeze.zip** from the assets below. No Git, Node.js, Python, or build tools are needed.

1. Unzip and move the **Unsqueeze** folder to a permanent location, such as Documents.
2. In Chrome, open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the folder containing `manifest.json`.
4. Pin Unsqueeze, choose your lens's squeeze factor, and reload Google Meet.

The download includes an offline **START-HERE.html** guide. You can also follow the [full installation guide](https://github.com/RamonLinares/unsqueeze/blob/main/docs/INSTALL.md).

## Included

- Seven squeeze presets plus custom factors from 1× to 3×.
- Fill-the-call crop or whole-image letterboxing.
- Efficient, Low power, and Source quality options.
- Optional camera-name filtering, live preview, and a camera-free test pattern.
- MIT license, source code, and privacy documentation.

Other participants receive the corrected video. Desktop Google Chrome and Google Meet are the intended setup; tested on macOS. Other browsers and operating systems have not been verified.

**Updating an existing copy:** replace its files at the same folder path, click Reload on its Chrome extensions card, and reload Meet. Do not install a second copy. GitHub installations update manually.

Use **Unsqueeze.zip** for the simplest installation. GitHub's automatically generated source archives are for developers; their loadable extension is in the `extension/` subfolder.
